# Mind Seed Systems

Mind Seed Systems is the GitHub home of **Mind Seed**: a local-first,
OS-integrated personal AI research system intended to develop persistent
cognition, governed memory, tools, automation, and safe interaction with an
owner's digital environment.

The project is private and experimental. Documentation distinguishes
implemented source, controlled experiments, planned work, and conceptual
direction; repository presence is never treated as deployment or capability
proof.

## What exists

- **`Mind-Seed`** — the private canonical core repository and historical Ardor
  lineage.
- **`.github`** — this public, non-sensitive organization standards and metadata
  repository.

Additional repositories will be created only for substantive artifacts with a
coherent owner and an independent versioning, deployment, interface, or
knowledge-domain boundary. Names of possible subsystems are not placeholders.
