# Support

Mind Seed Systems currently provides no public supported release, service-level
agreement, warranty, paid support, or compatibility guarantee.

Use repository issues for non-sensitive, reproducible problems concerning the
repository that owns the affected artifact. Include an exact version or commit,
environment, expected and observed behavior, and redacted evidence. Use the
feature or architecture forms for proposed capabilities and ownership changes.

Do not use issues for vulnerabilities, credentials, private data, account
access, billing, or protected knowledge. Follow [SECURITY.md](SECURITY.md).

The organization profile and this repository describe governance and metadata;
they are not a product download or evidence that the private Mind Seed runtime
is operational.
