# Contributing to Mind Seed Systems

Thank you for taking the time to contribute.

## Before opening an issue

- Check whether the relevant public repository already has a matching issue.
- Use the repository's issue templates when available.
- Share the smallest reproducible example and remove sensitive information.
- Report suspected security vulnerabilities privately as described in
  [SECURITY.md](SECURITY.md).

Do not place credentials, personal data, private source, internal system
details, or exploit material in public issues, pull requests, commits, or logs.

## Pull requests

Keep changes focused and explain:

- the problem being addressed;
- the behavior or documentation changed;
- the checks you ran and their results;
- any compatibility, security, or privacy effects.

Follow repository-local instructions and use short-lived branches where
practical. Do not mix unrelated changes into the same pull request.

## Verification

Run the checks documented by the target repository. Distinguish local testing
from deployment or live verification, and list any checks that were not run.

By contributing, you agree that your contribution may be reviewed, changed, or
declined to protect project quality, security, privacy, and scope.
