# Governance

Mind Seed Systems maintainers govern the organization's public repositories and
published metadata.

## Public changes

Changes should be reviewable, evidence-based, and limited to the repository
that owns the public artifact. Maintainers may request revisions or decline a
change when it conflicts with project scope, security, privacy, licensing, or
maintainability.

## Public-information boundary

This repository contains only information intended for public use. It must not
be used as an inventory of private projects or as a record of internal
architecture, infrastructure, operations, access, recovery, or release state.

Sensitive reports follow [SECURITY.md](SECURITY.md). Private implementation and
operational decisions remain in their authorized private locations.
