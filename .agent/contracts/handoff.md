# Handoff contract

Lead with the achieved outcome and actual delivery endpoint. Include only
material evidence: baseline, changed files/systems, decisions, relevant check
results and limitations, Git/PR/merge identity, and any remaining required action.
Separate local proof, hosted checks, merged source, release/deployment identity,
and observed live acceptance. Link the actual artifact or evidence.

For forced publication identify each intentionally bypassed eligible gate and
any external protection encountered. For blocked work name the exact action,
source of the constraint, completed independent preparation and concrete input
needed. Record adjacent follow-up separately. Omit empty ceremonial sections,
private data, secrets and claims that a tool or unrun check established success.
