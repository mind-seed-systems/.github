# Security policy

## Reporting a vulnerability

Do not report vulnerabilities or sensitive security information in a public
issue, discussion, pull request, commit, or log.

For this repository, use GitHub's
[private vulnerability reporting](https://github.com/mind-seed-systems/.github/security/advisories/new).
For another repository, follow the security policy published in that
repository.

Include only the information needed to understand and reproduce the issue:

- the affected public repository and version or commit, if known;
- a concise description of the impact;
- safe reproduction steps using synthetic or redacted data;
- relevant configuration and environment details with private identifiers
  removed;
- any mitigation already attempted.

Never submit credentials, personal data, private repository content, private
system details, or unredacted logs. If a credential may be exposed, identify
its type and location without including its value.

## Scope and response

This public policy does not promise a response time or support window. Reports
are assessed according to the affected public artifact and the information
available. Disclosure timing and remediation details are coordinated privately.
